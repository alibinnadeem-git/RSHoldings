# Hostinger Deployment

Upload the repository root into:

public_html/

Required at public_html root:

- index.html
- assets/

The site is static and requires no Node.js runtime.

## External Dependencies

Current version uses jsDelivr for:

- GSAP
- ScrollTrigger
- ScrollSmoother
- SplitText
- Three.js

The core semantic site remains visible if WebGL fails.

For fully self-hosted production, vendor these library files locally before
launch.
